Evidence standard and limits

Signals use only completed Kraken 1-hour candles. Simulated fills use the bid/ask quote observed during a GitHub job. There is no guarantee those fills would be obtainable from an exchange. Scheduled observations may be late or missing; gaps are recorded instead of being backfilled. This experiment does not trade or forecast profitability.

Published observations and state checkpoints are available in the repository. No exchange API credentials or private account data are used.
